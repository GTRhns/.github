# GTR HNS

**CS 1.6 / AMX Mod X · Hide & Seek (HNS) 开源插件生态**

**Open-source plugin ecosystem for CS 1.6 Hide & Seek servers**

</div>

GTR HNS 是一个专注 **Counter-Strike 1.6 / AMX Mod X** HNS（躲猫猫）比赛服务器插件开发的开源组织。旗下产品全部开源，涵盖皮肤系统、封禁管理、胜率统计、公共接口层与源码教程，并支持多语言。

GTR HNS is an open-source organization focused on developing plugins for **CS 1.6 / AMX Mod X** Hide & Seek (HNS) match servers. All products are open source — covering skin systems, ban/admin management, win-rate stats, a shared interface layer, and source-code tutorials, with multilingual support.

---

## 📦 产品线 / Products

| 仓库 | 说明 / Description |
|---|---|
| [hns-skin-system](https://github.com/GTRhns/hns-skin-system) | 独立皮肤系统（MySQL · 无限添加 · 租期/永久）· Standalone skin system |
| [hns-admin-system](https://github.com/GTRhns/hns-admin-system) | 独立封禁 + 权限管理系统 · Standalone ban & admin system |
| [HnsWinrateStats](https://github.com/GTRhns/HnsWinrateStats) | 胜率统计独立插件（SteamID 持久化 · 排行榜）· Win-rate stats plugin |
| [GTRhns-public](https://github.com/GTRhns/GTRhns-public) | HNS 比赛生态公共插件库 — 统一 INC 接口层 · Shared plugin library & INC API layer |
| [ic](https://github.com/GTRhns/ic) | 新版 HNS 插件 · New-generation HNS plugins |
| [hns-prefog](https://github.com/GTRhns/hns-prefog) | HNS 预加速辅助插件（PreFog 魔改）· Pre-accelerator helper |
| [skin-system-course](https://github.com/GTRhns/skin-system-course) | 皮肤系统教程开源课程（逐行精讲源码）· Open-source skin system course |

## 🛠️ 技术栈 / Tech Stack

- Counter-Strike 1.6 / AMX Mod X（Pawn 语言）
- MySQL 数据存储（皮肤 / 封禁 / 胜率等）
- 多语言支持：简体中文 · 繁體中文 · English · Русский · 한국어 · 日本語
